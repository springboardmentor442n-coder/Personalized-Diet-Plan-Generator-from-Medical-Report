# 🥗 Personalized Diet Plan Generator from Medical Report

This project uses AI and medical rule-based analysis to generate a
personalized **7-day diet plan** based on uploaded medical reports.

---

## 🚀 Features

- Upload medical report (PDF)
- Extract lab values automatically
- Detect medical conditions
- AI-generated 7-day diet plan
- Breakfast, Lunch, Dinner for each day
- Daily calorie estimation
- Vegetarian / Non-Vegetarian / Both options
- Diet plan displayed in table format
- Downloadable PDF report

---

## 🧠 Technologies Used

- Python
- Streamlit
- PyMuPDF
- Pandas
- Groq LLM API
- ReportLab
