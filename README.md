# AI-NutriCare

AI-Based Personalized Diet Plan Generator from Medical Reports.

## Features
- Upload medical reports (PDF)
- Extract key health parameters
- Detect health conditions
- Generate personalized diet plans
- Chat with AI assistant for explanations

## Tech Stack
- Python
- Streamlit
- OCR & NLP
- Machine Learning
- RAG-based Chatbot

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
