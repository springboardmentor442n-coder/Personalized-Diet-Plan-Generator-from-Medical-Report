# 🥗 AI Health & Diet Planner

An AI-powered web application that generates personalized diet and health plans using Google Gemini AI and Streamlit.

---

## 🚀 Features
- 📋 User-friendly dashboard for entering health data  
- 🧠 AI-generated personalized diet plans  
- 💧 Hydration tracking  
- 📄 Download diet plan as PDF  
- 🔐 Secure API key handling using `.env`  

---

## 🛠️ Tech Stack
- Python  
- Streamlit  
- Google Gemini AI  
- FPDF  
- python-dotenv  

---

## 📂 Project Structure
main_app.py # Streamlit dashboard
ai_engine.py # Gemini AI engine
nutrition_logic.py # BMR and calorie calculations
requirements.txt # Python dependencies
.gitignore # Protects API keys
